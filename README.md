# Gut Phocaeicola–Bacteroides balance in AD

Data and code repository for the working paper:

**"Gut balance of *Phocaeicola vulgatus* to *Bacteroides fragilis* is lower in Alzheimer's disease"**

Preprint: https://www.biorxiv.org/content/10.64898/2026.08.12.743985v2.abstract

---

## Repository Structure

```
gut_ad/
├── code/          # Analysis scripts (ADAM, MT-LDA, per-figure source code)
├── data/          # Per-stage processed data tables (raw metagenomes not included; see Data Availability)
└── figures/       # Per-figure source-data tables
```

---

## Data Availability

GAINS shotgun metagenomes and de-identified clinical metadata are held by the study group and are available from the corresponding author under a data-use agreement consistent with the governing institutional review board (IRB) protocol (H00021745).

AlzBiom metagenomes are publicly available in the European Nucleotide Archive under accession [PRJEB47976](https://www.ebi.ac.uk/ena/browser/view/PRJEB47976).

---

## Code Availability

All analysis code, including ADAM and MT-LDA implementation, is archived at Zenodo: https://doi.org/10.5281/zenodo.00000000-placeholder

Per-figure source-data tables and per-stage processed outputs are provided in this repository under `data/` and `figures/`.
